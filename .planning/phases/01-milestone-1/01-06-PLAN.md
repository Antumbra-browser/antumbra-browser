  **scripts/apply-patches.sh**
  This script applies all patches in patches/ in numeric order to a Firefox source tree.
  In CI it runs with --check (dry run). On the build machine it applies for real.

  ```sh
  #!/usr/bin/env bash
  # apply-patches.sh — Apply Antumbra patch series to a Firefox source tree.
  # Usage: apply-patches.sh [--check] [--firefox-src PATH]
  # --check: dry run only (git apply --check), no changes made.
  # --firefox-src: path to the Firefox source tree. Defaults to ../firefox relative to repo root.
  set -euo pipefail

  SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
  REPO_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"
  PATCHES_DIR="${REPO_ROOT}/patches"
  FIREFOX_SRC="${REPO_ROOT}/../firefox"
  DRY_RUN=0

  while [[ $# -gt 0 ]]; do
    case "$1" in
      --check)    DRY_RUN=1; shift ;;
      --firefox-src) FIREFOX_SRC="$2"; shift 2 ;;
      *) echo "Unknown flag: $1"; exit 1 ;;
    esac
  done

  if [[ ! -d "${FIREFOX_SRC}/.git" ]]; then
    echo "ERROR: Firefox source not found at ${FIREFOX_SRC}"
    echo "Set --firefox-src or ensure ../firefox is a git repository."
    exit 1
  fi

  APPLY_FLAGS="--3way"
  if [[ $DRY_RUN -eq 1 ]]; then
    APPLY_FLAGS="--check"
    echo "DRY RUN: checking patches apply cleanly to ${FIREFOX_SRC}"
  else
    echo "Applying patches to ${FIREFOX_SRC}"
  fi

  # Apply patches in numeric order (0000, 0100, 0200, 0300...).
  find "${PATCHES_DIR}" -name "*.patch" | sort | while read -r patch; do
    rel="${patch#${REPO_ROOT}/}"
    echo "  Applying: ${rel}"
    git -C "${FIREFOX_SRC}" apply ${APPLY_FLAGS} "${patch}"
  done

  echo "Done. $(find "${PATCHES_DIR}" -name "*.patch" | wc -l) patch(es) processed."
  ```

  **scripts/audit-prefs.py**
  This is the highest-value CI job. It parses prefs/antumbra.js, extracts every pref name,
  and verifies each one exists in the upstream Firefox pref files. Prefs with the "antumbra."
  prefix are allowlisted (they are our own prefs, not upstream prefs).

  ```python
  #!/usr/bin/env python3
  """audit-prefs.py — Verify every pref in antumbra.js exists in the upstream Firefox tree.

  Usage: python audit-prefs.py --prefs prefs/antumbra.js --firefox-src PATH
         python audit-prefs.py --prefs prefs/antumbra.js --ci (fetches pref files from upstream git)

  Exit 0: all prefs found or allowlisted.
  Exit 1: one or more prefs not found in the upstream tree.

  antumbra.* prefs are allowlisted — they are Antumbra-specific and not in upstream.
  Per ARCHITECTURE.md 2.2: a pref that no longer exists is silently ignored,
  so this check is the difference between a claimed protection and a real one.
  """
  import argparse
  import re
  import subprocess
  import sys
  from pathlib import Path

  # Prefs with these prefixes are Antumbra-specific and do not exist in upstream.
  ALLOWLISTED_PREFIXES = ["antumbra."]

  # Pref files to search in the upstream Firefox tree.
  UPSTREAM_PREF_FILES = [
      "browser/app/profile/firefox.js",
      "modules/libpref/init/all.js",
      "modules/libpref/init/StaticPrefList.yaml",
      "browser/app/profile/channel-prefs.js",
  ]


  def extract_pref_names(prefs_file: Path) -> list[str]:
      """Extract pref names from a .js pref file (pref("name", value) pattern)."""
      text = prefs_file.read_text(encoding="utf-8")
      # Match pref("name", ...) or pref('name', ...)
      pattern = re.compile(r'\bpref\s*\(\s*["\']([^"\']+)["\']')
      names = pattern.findall(text)
      return names


  def is_allowlisted(pref_name: str) -> bool:
      return any(pref_name.startswith(prefix) for prefix in ALLOWLISTED_PREFIXES)


  def search_pref_in_files(pref_name: str, search_paths: list[Path]) -> bool:
      """Return True if pref_name appears in any of the search paths."""
      escaped = re.escape(pref_name)
      for path in search_paths:
          if not path.exists():
              continue
          text = path.read_text(encoding="utf-8", errors="ignore")
          # Match pref name as a quoted string
          if re.search(r'["\']' + escaped + r'["\']', text):
              return True
      return False


  def fetch_pref_files_from_git(firefox_src: Path, tag: str = "FIREFOX_153_3_0esr_RELEASE") -> list[Path]:
      """Ensure the upstream pref files are available at the pinned tag."""
      fetched = []
      for rel in UPSTREAM_PREF_FILES:
          dest = firefox_src / rel
          if dest.exists():
              fetched.append(dest)
          else:
              # Try fetching from git at the pinned tag.
              try:
                  result = subprocess.run(
                      ["git", "-C", str(firefox_src), "show", f"{tag}:{rel}"],
                      capture_output=True, text=True, timeout=30
                  )
                  if result.returncode == 0:
                      dest.parent.mkdir(parents=True, exist_ok=True)
                      dest.write_text(result.stdout, encoding="utf-8")
                      fetched.append(dest)
              except Exception as e:
                  print(f"  WARNING: could not fetch {rel}: {e}", file=sys.stderr)
      return fetched


  def main():
      parser = argparse.ArgumentParser(description=__doc__)
      parser.add_argument("--prefs", required=True, type=Path, help="Path to antumbra.js")
      parser.add_argument("--firefox-src", type=Path, default=None,
                          help="Path to Firefox source tree")
      parser.add_argument("--ci", action="store_true",
                          help="Fetch pref files from git at pinned tag (for CI without full checkout)")
      args = parser.parse_args()

      if not args.prefs.exists():
          print(f"ERROR: prefs file not found: {args.prefs}", file=sys.stderr)
          sys.exit(1)

      if args.firefox_src is None:
          # Default: ../firefox relative to this script's repo root.
          script_dir = Path(__file__).parent
          args.firefox_src = script_dir.parent.parent / "firefox"

      pref_names = extract_pref_names(args.prefs)
      print(f"Auditing {len(pref_names)} prefs from {args.prefs}")

      search_paths = [args.firefox_src / rel for rel in UPSTREAM_PREF_FILES]
      if args.ci:
          search_paths = fetch_pref_files_from_git(args.firefox_src)

      missing = []
      allowlisted = []
      found = []

      for name in pref_names:
          if is_allowlisted(name):
              allowlisted.append(name)
          elif search_pref_in_files(name, search_paths):
              found.append(name)
          else:
              missing.append(name)

      print(f"  Found:       {len(found)}")
      print(f"  Allowlisted: {len(allowlisted)} (antumbra.* prefs; not in upstream)")
      print(f"  Missing:     {len(missing)}")

      if missing:
          print("\nMISSING PREFS (not found in upstream ESR 153 tree):", file=sys.stderr)
          for name in missing:
              print(f"  MISSING: {name}", file=sys.stderr)
          print("\nThese prefs no longer exist upstream and will be silently ignored.", file=sys.stderr)
          print("Remove them from prefs/antumbra.js or add them to ALLOWLISTED_PREFIXES.", file=sys.stderr)
          sys.exit(1)

      print("Pref audit PASSED.")
      sys.exit(0)


  if __name__ == "__main__":
      main()
  ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI workflow → upstream Firefox source | The patch-apply-check job clones the upstream tree from mozilla/gecko-dev; a compromised mirror would give a false "patches apply" result. |
| audit-prefs.py → upstream pref files | The pref audit fetches pref files from Mozilla's hg server; a fetch failure or tampered file would give a false pass. |
| scripts/apply-patches.sh → Firefox tree | On the build machine, apply-patches.sh modifies the Firefox source tree; running it with wrong arguments could corrupt the tree. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Tampering | CI fetches from upstream mirror | mitigate | Pin upstream fetch to the tag FIREFOX_153_3_0esr_RELEASE (a specific commit, not a moving branch). A tampered mirror at an old tag would fail the patch apply check since it would not match the tree the patches were generated against. |
| T-01-06-02 | Denial of Service | CI shallow clone times out | accept | A CI timeout fails the job visibly; it does not produce a false pass. The maintainer is notified via GitHub Actions. |
| T-01-06-03 | Elevation of Privilege | Self-hosted runner executing untrusted PR code | mitigate | ARCHITECTURE.md 10.2 states: "never run self-hosted runner jobs on pull requests from forks."   | T-01-06-04 | Repudiation | audit-prefs.py allowlist can be abused to skip real checks | mitigate | The ALLOWLISTED_PREFIXES list is in the script source, committed to the repo, and any change is visible in the git diff.
